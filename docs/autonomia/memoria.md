# AutonomIA: registro de Memória

O que cada edição deixou registrado para cobrar depois: promessa, prazo ou anúncio.

- O **passo 1** do roteiro `/autonomia` lê este arquivo e lista o que venceu. Registro vencido
  ganha resposta na rubrica Memória da edição, numa linha "Cobrado: ...", com fonte.
- O **passo 11** grava aqui os registros novos da edição publicada e marca como respondidos
  os que foram cobrados.
- Só entra aqui o que já saiu publicado numa edição. Este arquivo é versionado e público.

Estado: `aberto` ou `respondido na <edição>`.
