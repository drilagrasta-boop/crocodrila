# AutonomIA: mapa de fontes

Base da coleta semanal (passo 2 do roteiro `/autonomia`). Verificado na web em 23/11/2026;
o passo 11 do roteiro atualiza este arquivo quando uma fonte morre, muda de nome ou aparece.

## Como usar

- **Como ler**: `agente` = web aberta, lida por agente sem navegador; `navegador` = site que
  barra robô ou exige login, lido pelo navegador da editora, uma frente por vez;
  `navegador (a reconferir)` = a verificação automática foi bloqueada e a fonte ainda precisa
  ser confirmada pelo navegador; `só pista` = fechada e não assinada pela editora: serve para
  descobrir o fato, nunca para sustentar nota.
- **Acesso** é indício medido num artigo, não garantia para todos.
- Reportagem entra na nota com veículo e data, e com o documento primário ao lado quando existir.
- Nada deste arquivo dispensa abrir a fonte no dia: situação de projeto de lei, preço, cargo
  e data se leem na página, nunca aqui.
